# 輸入資料規格

這個資料夾不放真實學生資料。以下是應用程式目前採用的檔案契約。

## 答案檔

- 單科模式不限制答案檔名稱，會依工作表與欄位內容驗證
- 批次模式的建議檔名為 `年度_科目代號_ans.xlsx`
- 批次也接受 `ans`、`answer` 或 `答案`，例如 `115-C-答案-v2.xlsx`
- 必須包含工作表 `答案` 與 `向度`
- `答案` 的欄名使用科目代號加年級，例如 `C4`
- 無答案鍵的題目保留空白；輸出仍沿用原始題號
- 國語向度欄名使用 `三年級` 至 `八年級`
- 向度值在分組前會清除前後空白；例如 `修辭知識` 與尾端多空白的 `修辭知識 ` 會合併計算
- 英語向度欄名使用 `E3` 至 `E8`
- 自然向度欄名使用例如 `S4向度`
- 數學向度欄名使用例如 `M4` 的 `M41_向度` 與 `M42_向度`

## 作答檔

- 檔名開頭需包含年度、科目代號與年級，後方名稱可以自訂
- 例如 `115_C4.xlsx`、`115_C4_合併_校名修正.xlsx` 或 `115-C4-第一次匯出.xlsx`
- 第一列是欄位名稱，第二列起是學生資料
- 前 23 欄為學生與學校資訊，第 24 欄起為逐題作答
- 程式會優先依欄位名稱定位必要欄位；找不到時才沿用舊版欄位位置
- 第 1、2 欄建議分別使用 `總流水號`、`縣市流水號`，兩者均以文字保留
- `總流水號` 必須有值且不可重複；舊欄名 `流水號`、`學生流水號` 仍可辨識
- 第 14 欄使用 `性別代碼`，值以來源系統的 `1`、`2` 原樣保存；此欄不參與計分

匿名測試資料可由 `tests/create_fixture.R` 產生；可直接下載的檔案位於 `www/examples/`。
