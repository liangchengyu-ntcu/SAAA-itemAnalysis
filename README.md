# 115 成績分析 Shiny

這是一個本機優先的 R Shiny 專案，把既有批次計分程式拆成共用計算引擎與互動介面。計分、四捨五入、到考、缺考、特殊生、排名與 PR 規則沿用已確認版本，並同時支援：

- 單科模式：1 份答案檔搭配一個或多個年級作答檔
- 批次模式：上傳含多科、多年級資料的 ZIP
- 檔案上傳前檢查、工作清單、個別失敗不中止整批
- 與 Excel 共用資料來源的輸出報表預覽、分數分布與 ZIP 下載
- 新增縣市平均報表

## 快速開始

需求：R 4.3 以上，建議使用 RStudio 開啟 `115-score-shiny.Rproj`。

```r
source("install_dependencies.R")
shiny::runApp()
```

也可以在命令列執行：

```text
Rscript -e "shiny::runApp('.', launch.browser = TRUE)"
```

若目前不在專案目錄，可直接指定完整路徑：

```text
Rscript -e "shiny::runApp('C:/完整路徑/115-score-shiny', launch.browser = TRUE)"
```

預設單次上傳上限為 500 MB。可在啟動前設定環境變數 `SCORE_APP_MAX_UPLOAD_MB` 調整。

## 使用流程

1. 選擇「單科」或「整批 ZIP」。
2. 輸入年度並上傳檔案。
3. 按「檢查檔案」，確認每個科目／年級均為「可執行」。
4. 按「開始計算」。計算在背景工作中執行，介面不會被長時間鎖住。
5. 到「結果」頁選擇計算工作與輸出報表，或下載完整 ZIP。

結果清單會分別顯示計算、Excel 匯出及總耗時。報表預覽直接使用寫入 Excel 的同一份資料，頁面最多顯示前 100 列。

詳細欄位及命名方式見 [reference_data/README.md](reference_data/README.md)。

## 檔名辨識

- 單科模式的答案檔名稱不限，只要工作表與欄位內容正確。
- 作答檔需以「年度、科目代號、年級」開頭，後方名稱可以自訂。
- 例如 `115_C4.xlsx`、`115-C4-第一次匯出.xlsx` 均可辨識。
- 批次模式的答案檔需以年度與科目代號開頭，並包含 `ans`、`answer` 或 `答案`，例如 `115-C-答案-v2.xlsx`。
- 批次仍保留最小識別規則，才能可靠配對不同科目與年級。

## 匿名範例

應用程式的「使用說明」頁可直接下載：

- `www/examples/115_C_ans.xlsx`

範例全部由程式產生，不含真實學生資料。需要重建時執行：

```text
Rscript scripts/build_example_files.R
```

## 計算規則

- 答對率與平均值使用 R 的 `round(x, 6)` 四捨五入。
- 答案鍵空白的題目不納入計分。
- 向度名稱會先清除前後空白再分組，避免同名向度被拆成兩欄。
- 平均計算排除缺考者及特殊生代碼 `1`、`2`、`3`。
- 統計摘要採互斥分類：`學生數 = 到考數 + 缺考數 + 特殊生`。整份有效題目皆未作答者優先歸為缺考；其餘特殊生代碼 `1`、`2`、`3` 歸為特殊生；其餘歸為到考。
- 全體與縣市排名的母體為所有非缺考學生。
- `總流水號`、`縣市流水號`、學校代碼與班級代碼以文字處理。

## 效能設計

- 逐題計分採「每題一次、整欄學生同時計算」，沒有逐學生迴圈。
- 向度、總分、平均與排名使用矩陣、`rowSums()`、`colMeans()`、`aggregate()` 及 `data.table` 分組運算。
- 高精度答對率對相同答對題數使用查表，避免數萬名學生重複進行相同運算。
- Excel 使用 `writexl` 輸出；`openxlsx` 保留為輸入讀取與驗證工具。
- 個人成績、個人成績含題數及缺考名單依作業需求保留；大型資料的主要額外耗時會出現在詳細個人成績的組表與 Excel 寫檔。

## 輸出

每個科目／年級會產生 11 份 Excel：

1. 全體總答對率
2. 縣市平均
3. 各校平均
4. 各班平均
5. 縣市區域平均
6. 不同家庭背景平均
7. 缺考名單（含 `總流水號`、`縣市流水號`）
8. 個人成績含題數（含 `總流水號`、`縣市流水號`）
9. 全體名單成績含缺考（含 `答對題數`、`總流水號`、`縣市流水號`）
10. 個人成績（含原始作答、逐題計分、向度明細及兩種流水號）
11. 總平均

## 隱私與部署

- 上傳與輸出都位於 Shiny 工作階段專屬暫存資料夾；工作階段結束時刪除。
- 頁面只顯示不含姓名與流水號的彙總資料；含姓名與兩種流水號的完整名單只寫入下載報表。
- 目前設定為單一背景 worker，以降低同機記憶體尖峰。
- 含真實個資時，建議優先在受控的本機或內網環境使用。部署到外部平台前，仍需確認存取控制、日誌、備份、資料保存政策與合約要求。

## 修改指南

所有 `.R` 與 CSS 程式檔頂端都有繁體中文的「用途、修改入口、注意事項」，主要函式也標示輸入、回傳值及重要規則。常見修改位置如下：

| 想修改的內容 | 主要檔案 |
| --- | --- |
| 科目、年級、欄位別名、預覽選項 | `R/00_constants.R` |
| 四捨五入、高精度答對率、共用工具 | `R/01_utils.R` |
| Excel 必要欄位與資料驗證 | `R/10_validation.R` |
| 檔名規則、單科／批次自動配對 | `R/20_io.R` |
| 答案判定、缺考定義、向度及個人分數 | `R/30_scoring.R` |
| 到考／特殊生、平均、排名及 PR | `R/40_summaries.R` |
| Excel 報表內容、名稱與 ZIP | `R/50_exports.R` |
| 工作結果欄位與耗時 | `R/60_jobs.R` |
| 上傳、檢查、開始計算與狀態訊息 | `R/mod_run.R` |
| 摘要卡、分布圖、預覽與下載 | `R/mod_results.R` |
| 導覽頁、主題、說明文字與套件載入 | `app.R` |
| 導覽列品牌標誌 | `app.R`、`www/saaassessment_logo_horizontal_outlined.svg` |
| 色彩、間距、卡片及手機版 | `www/styles.css` |

若只調整文字或樣式，可修改後重新啟動應用檢查畫面。若調整計分、母體、排名或輸出欄位，應同步更新測試預期值並執行完整驗證。

## 驗證

專案包含匿名合成資料的端到端測試：

```text
Rscript tests/smoke_test.R
Rscript tests/module_test.R
```

測試會覆蓋單科與批次上傳暫存、檔案探索、向度名稱正規化、計分、兩種流水號、11 份匯出及結果壓縮；測試資料與輸出都建立在暫存目錄。
